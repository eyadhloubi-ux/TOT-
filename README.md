# TOT — حقيبة إعداد المدربين

العرض التدريبي الكامل لبرنامج TOT في ملف واحد (121 شريحة، 8 محاور).

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | العرض كاملاً، بصيغة محمية للعرض فقط |
| `favicon.png` | أيقونة الصفحة في المتصفح |
| `render.yaml` | إعداد النشر على Render |
| `.nojekyll` | يلزم فقط إذا نُشر على GitHub Pages |
| `robots.txt` | يمنع محركات البحث من فهرسة العرض وأرشفته |

## الحماية: العرض للمشاهدة فقط
- محتوى الصفحة مشفّر داخل الملف، فلا يظهر عند «عرض المصدر».
- النقر بالزر الأيمن، والتحديد والنسخ، والسحب، والطباعة، وحفظ الصفحة (Ctrl+S)، واختصارات أدوات المطوّر: كلها معطّلة.
- محركات البحث ممنوعة من فهرسة الصفحة.

> **مهم جداً:** إذا كان مستودع GitHub **عاماً (Public)** يستطيع أي أحد تنزيل الملفات مباشرة من صفحة المستودع.
> لذلك اجعل المستودع **خاصاً (Private)**، وانشر عبر **Render** (يدعم المستودعات الخاصة مجاناً).
> النشر على GitHub Pages من مستودع خاص يحتاج اشتراكاً مدفوعاً في GitHub.
>
> لا توجد حماية مطلقة على الويب: ما يظهر على الشاشة يمكن تصويره. هذه الإجراءات تمنع التنزيل والنسخ عند المستخدم العادي.

## الرفع والنشر (الطريقة المقترحة)
1. على GitHub: أنشئ مستودعاً جديداً باسم `tot-deck` واختر **Private**.
2. ارفع كل ملفات هذا المجلد إلى جذر المستودع (Add file ← Upload files)، بما فيها `.nojekyll` و`robots.txt`.
3. على Render: New ← **Blueprint** ← اربط حساب GitHub واختر المستودع؛ يقرأ Render ملف `render.yaml` وينشر الموقع.
4. يصلك رابط بالشكل: `https://tot-deck.onrender.com` — شاركه مع من تريد.

## التنقّل في العرض
- النقر أو الأسهم ← → أو عجلة الفأرة: الخطوة أو الشريحة التالية.
- زر `G`: شبكة الشرائح للانتقال السريع.
- زر `F`: ملء الشاشة.
- البطاقات القابلة للنقر تفتح شرائحها، وزر «العودة» يرجع للشريحة الأم.

> الخطوط تُحمَّل من Google Fonts، فيحتاج العرض اتصالاً بالإنترنت لتظهر بخطها الأصلي.
